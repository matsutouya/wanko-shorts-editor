# わんこショート編集

犬の動画から縦型ショートを作るための、日本語画面のローカル動画編集ツールです。[AutoBroll](https://github.com/andriidrok1/autobroll) 0.4.0 を基にしています。元の著作権表示と MIT ライセンスは [LICENSE](LICENSE) に残しています。元の説明書は [README.upstream.md](README.upstream.md) です。

## 起動する

必要なのは Node.js 20以上と FFmpeg です。Macで FFmpeg がなければ `brew install ffmpeg` で入れられます。

```bash
git clone https://github.com/matsutouya/wanko-shorts-editor.git
cd wanko-shorts-editor
npm ci
npm start
```

Chromeで `http://localhost:5173/` を開きます。動画の読み込みと手動編集に追加のAPIキーは必要ありません。動画と編集内容は自分のパソコンに保存されます。

## 犬のショートを作る

1. 最初の画面で動画を選び、「編集を始める」を押します。動画は複数選べます。
2. 右側の「見せ場」タブで動画の場面を一覧表示します。「細かく見る」に切り替えると24枚で確認できます。静止画を押すとその位置へ移動します。この機能にAPIキーは必要ありません。
3. 下のタイムラインで使う場面を決めます。`S` で分割、`Delete` で選択した区間を削除できます。動画の端をドラッグすると長さを調整できます。
4. 文字を出したい位置に再生バーを置き、右側の「字幕」タブで「再生位置に文字を追加」を押します。文章、表示時間、上下位置を調整できます。
5. 音楽を使う場合は左側の「音楽を追加…」から選びます。
6. 「確認用」で試しのMP4を作り、問題なければ「MP4を書き出す」を押します。完成した動画は「動画を保存」からダウンロードできます。

動画は1080×1920の縦型です。元の動画ファイルを直接書き換える編集ではありません。YouTubeへの投稿機能はありません。

## Claude Codeから使う

このフォルダをClaude Codeで開くと、同梱の `.mcp.json` から編集用MCPを利用できます。新しいMCPツールが見えない場合はClaude Codeを開き直してください。`npm start` を起動したまま、たとえば次のように指示できます。

> このプロジェクトを日本語で操作してください。まず `scene_overview` で犬の動画を静止画一覧として確認し、面白い場面の候補と時刻を3つ挙げてください。私が選んだ場面を中心に30秒以内の縦型ショートを試作してください。元動画は残し、完成候補を私に見せてから修正してください。投稿はしないでください。

`scene_overview` は1本の動画から12枚の静止画をClaudeに渡します。Claudeは動画全体を連続視聴するのではなく、静止画や指定したフレームを見て操作します。見せ場の最終判断はプレビューで確認してください。

## 任意のAI機能

「音声で並べ替え」「無音カット」「音声から字幕を作る」などは、主に話し声のある動画向けです。使う場合は `npm run setup -- --cpu` を実行して WhisperX を準備します。Gemini APIキーを使う機能は `.env` に `GEMINI_API_KEY` を設定します。Pexels素材検索は `PEXELS_API_KEY` が必要です。犬の映像を手動でカットしてテロップを付けるだけなら、これらは不要です。

Macではレンダリング時にインストール済みの Google Chrome を利用します。別のChrome実行ファイルを使う場合は `REMOTION_BROWSER_EXECUTABLE` を指定できます。
